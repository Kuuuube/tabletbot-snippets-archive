**KDE Provides Broken Default Virtual Tablet Settings**

- Open `Drawing Tablet` in the KDE System Settings
- Set `Map to screen` to `All Screens` and `Mapped Area` to `Stretch and Fill`.
- If there is a dropdown with multiple devices you may need to set this on all devices. Including the OpenTabletDriver Virtual Device.
- In OpenTabletDriver, right click the `Display` area -> `Set to display` -> Select the display you would like to map to. Then Apply/Save.
